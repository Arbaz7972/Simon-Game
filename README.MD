# 🎮 Simon Game

A fun and interactive **Simon Memory Game** built using **HTML, CSS, and JavaScript**.

## 🚀 Features

* 🎨 Color sequence memory game
* 🧠 Increasing difficulty
* 🏆 Score tracking
* ⚡ Fast and interactive gameplay
* 🔄 Restart and play again

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript

## 🎯 How to Play

1. Press any key to **start the game**.
2. Watch the color sequence carefully.
3. Click the colors in the **same order**.
4. Each level adds a new color to the sequence.
5. Make a mistake and the game is over.
6. Try again and beat your highest score! 🏆
